## Verified-against-source corrections to the TRD-v2 brief

TRD-v2's "Brief for the TRS" section names specific files/structs for the
implementer to touch. Cross-checked against the actual v1.0.1 tree
(2026-07-24) — two naming corrections surfaced and are threaded through the
plan/tasks files:

1. **`RunStatsRow` does not exist.** The actual struct is `TaskRunAggregate`
   (`plumb/adapters/storage_sqlite.py:36-64`), populated by
   `aggregate_runs_for_task()` (`:719-788`), consumed by
   `plumb/_http_stats.py::compute_task_stats`. All task references use the
   verified name.
2. **`core/errors.py` has no `NotFoundError`.** FR-RESUME-4 needs one for
   `resume_run`. `plumb/_http_stats.py` already defines a *local*
   `NotFoundError(Exception)` for a different purpose (empty `/stats`
   window) — that class must not be reused; a new
   `plumb.core.errors.NotFoundError(PlumbError)` is Task 1.

Everything else in TRD-v2's brief (files to touch, priority tiers, §15.5→§15.7
ordering dependency, the `dollar_cost` CLI-scope correction) was verified
accurate against source and carried through unchanged.

## Decisions already made (do not re-litigate)

All resolved in TRD §15 / TRD-v2, cited so this TRS doesn't re-derive them:

- **D-a1 (dollar_cost vs tokens sourcing):** split — `dollar_cost` explicit-only, `tokens_in`/`tokens_out` explicit-wins-else-auto-fill. (TRD-v2 AMENDMENT 2026-07-24, Resolution 2; TRD §15.7 FR-USAGE-3.)
- **D-a2 (resume_run + set_usage interaction):** last-wins overwrite, not accumulation. (TRD §15.7 FR-USAGE-4.)
- **FR-USAGE-3a (cost derivation):** permanent non-goal — plumb MUST NOT compute `dollar_cost` from tokens, ever, in any release. (TRD §15.7.)
- **D-b1 (attributes validation):** fail-closed on write, never raise on read. (TRD §15.8 FR-ATTR-3.)
- **D-b2 (attributes size cap):** ~8KB soft cap at the API boundary. (TRD §15.8 FR-ATTR-4.)
- **D-b3 (attributes scope):** `spans` only, not `runs`, for v1.1. (TRD §15.8 FR-ATTR-1.)
- **P1-b sign-off:** met 2026-07-24 by the verified Codex/Claude backend-shape finding; `spans.attributes` is confirmed **included** in this migration. (TRD-v2 Resolution 4.)
- **FR-USAGE-6 / FR-STATS-1 (coverage count):** option (a) chosen — `COUNT(dollar_cost)` alongside the sum, no schema change. Rejected: `runs.cost_source` discriminator, caller-owns-the-caveat. (TRD-v2 Resolution 1.)
- **Backlog sweep:** no other backlog entry is migration-locked; the five DDL statements in DATA-MIG-2 are the complete `ALTER` list. (TRD-v2 "Backlog sweep" section.)

  builds directly on the shipped `SCHEMA_VERSION=1` codebase.
- **Internal task-ordering constraints** (binding, not just suggested):
  migration (Task 2) before any column-writing task; §15.5 (Task 4) before
  §15.7's auto-fill (Task 9); `NotFoundError` (Task 1) before `resume_run`

  consumer for this whole release — see TRD-v2 "v3 dependency edges" for
  which atlas maturity level (L0/L1/L2/L3) needs which feature. Not a code

  repo.
